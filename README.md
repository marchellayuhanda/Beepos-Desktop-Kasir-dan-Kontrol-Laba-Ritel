# Beepos-Desktop-Kasir-dan-Kontrol-Laba-Ritel
Beepos Desktop adalah aplikasi kasir Windows untuk minimarket dan toko ritel. Dilengkapi fitur POS beserta layar pelanggan, pengaturan harga grosir bertingkat, analisis perputaran stok (ITO &amp; DSI) pendeteksi barang mati, sistem poin loyalitas member, hingga laporan laba rugi bersih secara riil untuk mengontrol arus kas dan keuntungan usaha.
